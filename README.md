Los documentos mantienen su organización técnica y académica, con las portadas normalizadas al formato institucional SENA. Las carpetas `version-1.0`, `version-2.0`, `version-2.5.4` y `version-2.5.5` mantienen separados los lotes recibidos y sus revisiones; consulta la fecha y el estado indicados dentro de cada documento antes de usarlo como referencia vigente.

## Versión vigente

La revisión documental 2.5.5 tiene corte al 28 de octubre de 2026. Consulta el [catálogo de entregables](./00-governance/catalogo-entregables-2026-10-28.md) y descarga los [DOCX y PDF versionados](./14-deliverables/version-2.5.5/). La auditoría separa código presente de pruebas ejecutadas; el paquete incluye portadas SENA uniformes para los doce documentos.
